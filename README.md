## Proyectos / Projects

### ai-rag-api

**Stack:** Python, FastAPI, LangChain, LangGraph, OpenAI, FAISS, Azure AI Document Intelligence, SQLAlchemy, Streamlit, Docker, Docker Compose

**ES:** Plataforma de preguntas y respuestas sobre documentos PDF con arquitectura RAG. Permite subir documentos, indexarlos y consultarlos en lenguaje natural: las respuestas se generan con un modelo de lenguaje a partir del contenido recuperado, con respuesta en tiempo real (streaming) e historial por sesión.

**EN:** Question-answering platform over PDF documents using a RAG architecture. Users upload and index documents and query them in natural language: answers are generated by a language model from the retrieved content, with real-time streaming and per-session history.

**Base de datos / Database:** SQLite local (rag.db) para historial, sesiones y estadísticas, e índice vectorial FAISS para la búsqueda semántica. / Local SQLite (rag.db) for history, sessions and statistics, and a FAISS vector index for semantic search.

**Qué puede hacer / What it can do:**
- Subir PDFs, reindexar y listar los documentos indexados. / Upload PDFs, reindex and list the indexed documents.
- Responder preguntas sobre los documentos, incluida la respuesta en streaming. / Answer questions about the documents, including streaming responses.
- Guardar el historial por sesión; exportarlo, importarlo y borrarlo. / Store per-session history; export, import and delete it.
- Estadísticas de uso y ranking de las preguntas más frecuentes. / Usage statistics and ranking of the most frequent questions.
- Endpoint de salud y despliegue con Docker Compose. / Health endpoint and Docker Compose deployment.

### meta-ai-agent

**Stack:** Go (GORM), Python (FastAPI), SQLite, Google Calendar API, Docker, Docker Compose

**ES:** Sistema de gestión y agendamiento automático de citas por WhatsApp para un consultorio de kinesiología, con panel web de administración. Un asistente conversacional atiende al paciente y el consultorio gestiona pacientes, fichas, diagnósticos y ejercicios desde el panel.

**EN:** Appointment management and automated scheduling system over WhatsApp for a physiotherapy clinic, with a web admin panel. A conversational assistant serves the patient, and the clinic manages patients, records, diagnoses and exercises from the panel.

**Base de datos / Database:** SQLite local (agenda.db y meta_agent.db), accedida con GORM desde Go. / Local SQLite (agenda.db and meta_agent.db), accessed with GORM from Go.

**Qué puede hacer / What it can do:**
- Asistente por WhatsApp para agendar, reagendar y cancelar citas y consultar horas disponibles. / WhatsApp assistant to book, reschedule and cancel appointments and check available slots.
- Sincronización de la agenda con Google Calendar. / Agenda synced with Google Calendar.
- Panel web con dashboard, calendario, agenda y búsqueda de pacientes; marcado de citas realizadas. / Web panel with dashboard, calendar, agenda and patient search; mark appointments as completed.
- Fichas de pacientes y registro de diagnósticos. / Patient records and diagnosis tracking.
- Biblioteca de ejercicios asociada a diagnósticos. / Exercise library linked to diagnoses.
- Configuración del comportamiento del bot. / Bot behavior configuration.

**ES:** Prueba de concepto de un asistente conversacional en Microsoft Teams sobre Azure: recibe mensajes del Bot Framework y de webhooks salientes de Teams y los procesa con una API en Python/FastAPI respaldada por PostgreSQL.

**Base de datos / Database:** PostgreSQL con esquema SQL propio (poc_azure_ia.sql). / PostgreSQL with its own SQL schema (poc_azure_ia.sql).

**Qué puede hacer / What it can do:**

- Endpoints de prueba y diagnóstico (conexión a la base de datos, rutas, salud). / Test and diagnostic endpoints (database connection, routes, health).
